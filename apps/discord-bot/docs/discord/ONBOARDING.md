# Onboarding

`#start-here` is a canonical managed panel. Its buttons use stable `slice:onboarding:*` IDs and are republished by setup without duplication. Account and identity buttons are safe website-handoff seams only; they never collect credentials in Discord.

Manual QA: run `/setup server`, confirm the panel updates in place, click each button, and verify every response is ephemeral and contains no credential form.
