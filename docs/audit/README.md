# Audit index

The audit documents are evidence and planning aids. Current code/runtime and
`docs/CURRENT_SYSTEM_STATE.md` are the current engineering authority; dated
forensic documents retain their historical context.

- `FULL_CODEBASE_AUDIT.md` — historical forensic baseline
- `ROUTE_INVENTORY.md` — active route classification
- `SOURCE_OF_TRUTH_MATRIX.md` — domain authority matrix
- `ARCHITECTURE_DRIFT.md` — reconciliation candidates
- `DEAD_CODE_CANDIDATES.md` — candidates only, not deletion authority
- `CLEANUP_PLAN.md` — controlled cleanup sequence
- `TEST_COVERAGE_AUDIT.md` — audit-era verification evidence
- `DEPENDENCY_CONFIG_AUDIT.md` — package/config findings
