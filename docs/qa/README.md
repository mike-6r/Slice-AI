# Slice QA archive

This folder contains verification records and captured evidence. It is not
runtime application code.

- `admin/` — Admin route, review, asset-operations, and account QA
- `beta/` — beta release gates, collector audits, and responsive evidence
- `collector/` — collector and offering audits
- `discord/` — Discord bot QA and release records
- `stripe/` — Stripe architecture and sandbox QA records
- `web/` — web visual QA and bug-fix records
- `screenshots/` — captured browser evidence

The authoritative application remains at the repository root, especially
`src/`, `server/`, `apps/`, `public/`, and `scripts/`.
